# I6 Path Help Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every host-path field has a "How do I find this path?" popover with the factory machine's copy-path steps, and the server accepts `~` and `~/…`, storing the absolute realpath.

**Architecture:**
- Server: one module `apps/server/src/host-path.ts` (`expandHome`, `resolveHostFolder`) is used by `config.ts` and `ProjectService`, and later by I5's local-folder fields. A new authenticated `GET /api/host` returns `{ platform, hostname, home }`.
- Web: a reusable `PathField` (a `FormField` with an `action`) renders `PathHelp`, a Radix popover whose content alone reads `hostQueryOptions` (cached forever, prefetched where path fields mount). Add project and Change path use it.
- Primitive: `PopoverContent` closes instantly on Esc and exports `PopoverTitle` and `PopoverDescription`.

**Tech Stack:**
- TypeScript, pnpm monorepo.
- `apps/web`: React 19, Vite, TanStack Router and Query, Tailwind 4, Radix (`radix-ui`), `lucide-react`.
- `apps/server`: Fastify with `fastify-type-provider-zod`.
- `packages/shared`: Zod.
- Tests: Vitest with Testing Library (jsdom). Lint: Biome.
- Playwright, for evidence only, through the harness outside the repo.
- No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-23-i6-path-help-design.md` (branch `spec/i6-path-help`). Decision issue #134. Read the spec alongside this plan. §n refers to a spec section and AC n to an acceptance criterion. Q/R/D refer to its decisions.

  ```ts
  // apps/server/src/host-path.ts
  import { realpath, stat } from "node:fs/promises";
  import os from "node:os";
  import path from "node:path";
  import { MSG } from "@open-factory/shared";
  import { FieldError } from "./errors.ts";
  import { FIELD_MSG } from "./field-messages.ts";

  /** `~` and `~/…` → the factory user's home (`os.homedir()`, which honours $HOME like the shell). No resolve:
   *  a host-path field must reject a relative path, not resolve it against the server's cwd. */
  export function expandHome(p: string, home = os.homedir()): string {
    if (p === "~") return home;
    return p.startsWith("~/") ? path.join(home, p.slice(2)) : p;
  }

  /** The realpath of an existing folder on the factory's machine, or a FieldError on `field`. */
  export async function resolveHostFolder(field: string, input: string, home = os.homedir()): Promise<string> {
    const p = expandHome(input.trim(), home);
    if (!path.isAbsolute(p)) throw new FieldError(field, MSG.hostPathStart);
    const missing = () => new FieldError(field, FIELD_MSG.<noFolderKey>);
    try {
      const real = await realpath(p);
      if (!(await stat(real)).isDirectory()) throw missing();
      return real;
    } catch (err) {
      throw err instanceof FieldError ? err : missing();
    }
  }
  ```
