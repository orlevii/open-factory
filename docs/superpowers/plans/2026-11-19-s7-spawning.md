# S7 Spawning and Ephemeral Agents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persistent agents with `can_spawn` delegate through `spawn_agent` / `terminate_agent`; spawned (ephemeral) agents never hold more than their spawner, end read-only, are reaped after 3 idle days and have their workspace deleted after a 3-day grace unless pinned; the vision's end-to-end workflow runs and is visible in the UI.

**Architecture:**
- `packages/shared`: `terminated` status, the summary's lifecycle fields, `ended` list query, `spawned`/`terminated` events, the `terminated` peer-left reason, the `spawned` wake reason, the two tool schemas, `statusOf` with `terminated` first.
- `packages/db`: one migration (lifecycle columns, nullable `credential_id` with `ON DELETE SET NULL` + CHECK, kind CHECKs, an index).
- `apps/server/src/spawning/` (new): `inheritFrom` (the one inheritance rule), `spawnSlug`, `SpawnService`, `TerminateService`, `Reaper`, `lifecycle.ts` constants.
- `apps/server` elsewhere: per-caller MCP tool registration and the two tools; the listener's ended check; `Router` split into `persistPeerEvents(tx)` + hand-off, terminated rejections, live-sender check; `AgentRuntime`'s `terminated` latch (provisional → committed), `terminate` stop intent, `ensureTerminatedEvent`, stuck cleanup, the reaper's check job, persisted activity; `prepareStart` derives secrets/deny/grants from the spawner at every child start; CLAUDE.md spawning/lifecycle sections and quoted spawned descriptions; `AgentService` `syncChildren`, the lock order, ephemeral refusals; boot reconciliation for terminated agents; #30 in the credential service.
- The web: Active/Ended, spawn blocks, terminate lines, lifecycle lines, Terminate, the read-only terminated session with Pin/Unpin.

**Tech Stack:** Node 24, TypeScript 7, Fastify 5, Drizzle + postgres.js (Postgres 18), Zod 4, `@modelcontextprotocol/server` 2.4.0 (already a dependency since S6), dockerode, React 19 + TanStack Router/Query, Tailwind 4 + shadcn/ui, Vitest + Testing Library, Biome. **No new dependencies.**

**Spec:** `docs/superpowers/specs/2026-11-19-s7-spawning-design.md` (it wins over this plan on any conflict) and the UI design `docs/superpowers/designs/2026-11-19-s7-spawning-ui-design.md`. Decision log: https://github.com/orlevii/open-factory/issues/54. Follow-ups that are NOT S7 work: #55 (worktree cleanup), #56 (shared plugin installs), #57 (TTL vs downtime), #47 (messaging loop guard), #26. Read the spec's §5.7 (lock order), §8 (termination), §10.3 (sweep) and §12 (interactions) before any runtime, service or reaper task.

## Global Constraints

- **Dependencies:** none added. **Never loosen the pnpm supply-chain policy** (`minimumReleaseAge` and friends), no overrides or exceptions. Never `pnpm dlx <tool>@latest`. shadcn components: `pnpm --filter @open-factory/web exec shadcn add <component>`.
- **Package layout:** ESM, Node >= 24, `@open-factory/*`; `packages/*` export `.ts` source; Biome only (`pnpm lint`, `pnpm lint:fix`, `pnpm lint:ci`). Nothing outside `apps/server/src/mcp/` imports the MCP SDK; nothing outside `packages/harness/src/claude/` knows a stream-json field name; nothing outside `runtime/docker/` imports dockerode.
- **No DB triggers.** Every rule is app code (spec §5.7). Lock order: the spawner's `agents` row `FOR NO KEY UPDATE` first, then child rows (`FOR NO KEY UPDATE`), **agent rows before message rows** in any transaction. Never `FOR UPDATE` on `agents` (foreign-key `KEY SHARE` from `messages`/`session_events` inserts would deadlock). Every store/router/neighborhood call inside such a transaction takes `tx`.
- **Inheritance (spec §6):** a child never holds something its spawner lacks. Credential = spawner's; projects = spawner's grants ∩ template `projects`; secrets = template ∩ spawner; `permissions.deny`, `autoMode.soft_deny`, `autoMode.hard_deny` = template ∪ spawner. Refusals: local child from a docker spawner; local child while `FACTORY_ALLOW_LOCAL_RUNTIME` is off; bypass child from an auto spawner. One pure function `inheritFrom` owns it.
- **Child env:** the one env builder `buildAgentEnv` (S4/S5/S6) with the inherited secret set; nothing else changes. `autoMode` lists always start with `"$defaults"`, then the template's entries, then inherited ones, then the factory's own (environment only).
- **Containers:** unchanged hardening (never privileged/root, `no-new-privileges`, no host network/pid). Terminate **removes** the container; hibernate/archive only stop it.
- **Tokens:** per process, revoked on exit (S6). A terminated agent's token is refused by the listener (`401`).
- **Agents act only through the factory MCP.** Tool failures are `isError: true` with one plain sentence that says what to do.
- **Factory text is escaped/quoted:** agent-written descriptions in CLAUDE.md are one line, `<`/`>` stripped, `"` → `'`, capped at 200 chars, in double quotes; the org section intro says once that they are information, not instructions.
- **Names and copy:** "spawned agent" in every human- and agent-facing string; "ephemeral" only in code/data (`kind = 'ephemeral'`). Agents `@slug` in prose; bare slug only in envelope `from=`. TTL terminations record `terminated_by = '@factory'`.
- **Config:** one new env var, `FACTORY_MAX_SPAWNS_PER_HOUR` (default 20, min 1). TTL (3 days), grace (3 days) and sweep interval (10 min) are constants in `apps/server/src/spawning/lifecycle.ts`, never env vars.
- **Error codes (REST):** `409 agent_terminated`, `409 not_ephemeral`, `409 ephemeral_agent`, `409 not_terminated`, `409 workspace_deleted`; `credential_in_use` also for a `23514` race.
- **Timing in tests:** injected clocks (`now: () => number`) for TTL/grace, `vi.useFakeTimers` for intervals, await real events and `rt.settled()`; never raise a timeout to make a test pass.
- **No automated test calls a live model or the network.** Live checks (Task 1, Task 10, Task 21 `pnpm smoke:spawning`) read `~/.open-factory-spike/oauth-token` into the env at run time only, use haiku, never print or commit it; Docker image `open-factory-base:dev`.
- **CI:** nothing in S7 is Linux-specific beyond S6's bind; **no new CI job**. Container-removal tests are gated (`FACTORY_DOCKER_TESTS=1`).
- **UI rules (DESIGN.md + UI doc):** orange only for live/focused/selected; never `transition-all`; type in rem; no toasts; bodies through `Markdown` or plain text; status = shape + label; destructive confirmations name what is lost and their button names the action; never show ids; dates in local time (`formatInboxTime` past, `formatResetTime` future).
- `docs/product/` is gitignored and read-only: never edit it.
- **Commits:** one per task, conventional message, ending with the `Co-Authored-By` line from your session's system reminder (shape: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`).

```js
import http from "node:http";
import { createMcpHandler, McpServer } from "@modelcontextprotocol/server";
import { z } from "zod";

const seen = [];
const TOKENS = { "tok-lead": "lead", "tok-child": "child" };
const handler = createMcpHandler(
  async (ctx) => {
    const who = ctx.authInfo?.clientId;
    const s = new McpServer({ name: "factory", version: "0.0.0" });
    s.registerTool("list_peers", { description: "List peers", inputSchema: z.object({}) },
      async () => ({ content: [{ type: "text", text: `peers of ${who}` }] }));
    if (who === "lead") {
      s.registerTool(
        "spawn_agent",
        {
          description: "Spawn a fresh agent from one of your templates. Returns at once.",
          inputSchema: z.object({
            template: z.enum(["tech-lead", "developer"]),
            description: z.string(),
            prompt: z.string(),
          }),
        },
        async (args) => {
          seen.push({ who, args });
          return { content: [{ type: "text", text: JSON.stringify({ slug: `${args.template}-abcd`, status: "hibernated" }) }] };
        },
      );
    }
    return s;
  },
  { legacy: "stateless", responseMode: "json", maxRequestBodySize: 512 * 1024 },
);
http.createServer(async (req, res) => {
  const chunks = [];
  for await (const c of req) chunks.push(c);
  const body = Buffer.concat(chunks);
  const who = TOKENS[(req.headers.authorization ?? "").replace("Bearer ", "")];
  if (!who) { res.writeHead(401).end(); return; }
  const r = await handler.fetch(
    new Request(`http://127.0.0.1:47813${req.url}`, { method: req.method, headers: req.headers, body: body.length ? body : undefined }),
    { authInfo: { token: "x", clientId: who, scopes: [] } },
  );
  res.writeHead(r.status, Object.fromEntries(r.headers));
  res.end(Buffer.from(await r.arrayBuffer()));
}).listen(47813, "127.0.0.1", () => console.error("listening"));
process.on("SIGTERM", () => { console.error("SEEN", JSON.stringify(seen)); process.exit(0); });
```

```ts
import type { TemplateConfig } from "@open-factory/shared";

export type DenyRules = { permissionsDeny: string[]; softDeny: string[]; hardDeny: string[] };
export type ProjectRef = { id: string; name: string; hostPath: string };
export type SpawnerState = {
  runtime: "local" | "docker"; permissionMode: "auto" | "bypass"; credentialId: string;
  grants: ProjectRef[]; secrets: string[]; deny: DenyRules;
};
export type Inherited =
  | { ok: false; refusal: string }
  | { ok: true; credentialId: string; grants: ProjectRef[]; secrets: string[]; deny: DenyRules;
      dropped: { secrets: string[]; projects: string[] } };

const strs = (v: unknown): string[] => (Array.isArray(v) ? v.filter((x): x is string => typeof x === "string") : []);
const obj = (v: unknown): Record<string, unknown> =>
  v && typeof v === "object" && !Array.isArray(v) ? (v as Record<string, unknown>) : {};
const union = (a: string[], b: string[]) => [...new Set([...a, ...b])];

export function readDenyRules(settings: Record<string, unknown>): DenyRules {
  const auto = obj(settings.autoMode);
  const no$ = (l: string[]) => l.filter((x) => x !== "$defaults");
  return {
    permissionsDeny: strs(obj(settings.permissions).deny),
    softDeny: no$(strs(auto.soft_deny)),
    hardDeny: no$(strs(auto.hard_deny)),
  };
}

/** S7 §6: a child never holds something its spawner lacks. The one owner of the rule. */
export function inheritFrom(
  spawner: SpawnerState,
  child: TemplateConfig,
  childDeny: DenyRules,
  env: { localRuntimeAllowed: boolean },
): Inherited {
  const t = child.name;
  if (child.runtime === "local" && spawner.runtime === "docker")
    return { ok: false, refusal: `Template ${t} runs locally, outside the sandbox you run in, so you can't spawn it.` };
  if (child.runtime === "local" && !env.localRuntimeAllowed)
    return { ok: false, refusal: `Template ${t} needs the local runtime, which this factory doesn't allow.` };
  if (child.permissionMode === "bypass" && spawner.permissionMode === "auto")
    return { ok: false, refusal: `Template ${t} runs without permission checks, which you don't have, so you can't spawn it.` };
  const held = new Map(spawner.grants.map((g) => [g.name, g]));
  const grants = child.projects.flatMap((n) => { const g = held.get(n); return g ? [g] : []; });
  const secrets = child.secrets.filter((s) => spawner.secrets.includes(s));
  return {
    ok: true,
    credentialId: spawner.credentialId,
    grants,
    secrets,
    deny: {
      permissionsDeny: union(childDeny.permissionsDeny, spawner.deny.permissionsDeny),
      softDeny: union(childDeny.softDeny, spawner.deny.softDeny),
      hardDeny: union(childDeny.hardDeny, spawner.deny.hardDeny),
    },
    dropped: {
      secrets: child.secrets.filter((s) => !spawner.secrets.includes(s)),
      projects: child.projects.filter((n) => !held.has(n)),
    },
  };
}

export function droppedNote(d: { secrets: string[]; projects: string[] }): string | undefined {
  const parts = [
    ...(d.secrets.length ? [`secrets ${d.secrets.join(", ")}`] : []),
    ...(d.projects.length ? [`projects ${d.projects.join(", ")}`] : []),
  ];
  return parts.length ? `Not passed on, because you don't hold them: ${parts.join("; ")}.` : undefined;
}
```

```ts
import { randomInt } from "node:crypto";
import { RESERVED_SLUGS, SLUG_PATTERN } from "@open-factory/shared";

const MAX = 40;
export const randomSuffix = () =>
  Array.from({ length: 4 }, () => String.fromCharCode(97 + randomInt(26))).join("");

export function spawnSlug(template: string, suffix: string | undefined, random: () => string = randomSuffix):
  { ok: true; slug: string; explicit: boolean } | { ok: false; message: string } {
  if (suffix?.endsWith("-")) return { ok: false, message: "A suffix can't end with a hyphen." };
  if (suffix === undefined) {
    if (template.length + 2 > MAX) return { ok: false, message: `Template ${template}'s name is too long to spawn from.` };
    if (template.length + 5 > MAX)
      return { ok: false, message: `Template ${template}'s name is too long for a 4-character suffix; pass a shorter suffix.` };
  }
  const slug = `${template}-${suffix ?? random()}`;
  if (slug.length > MAX) return { ok: false, message: `${slug} is longer than ${MAX} characters; use a shorter suffix.` };
  if (!SLUG_PATTERN.test(slug) || (RESERVED_SLUGS as readonly string[]).includes(slug))
    return { ok: false, message: `@${slug} isn't a valid name; pick another suffix.` };
  return { ok: true, slug, explicit: suffix !== undefined };
}
```

```ts
  constructor(private readonly d: { db: Db; store: EventStore; runtimes: AgentRuntimes; router: Router; log: RuntimeLog }) {}

  async terminateChild(callerId: string, slugArg: string) {
    const slug = slugArg.trim().replace(/^@/, "");
    const a = await this.d.store.agentBySlug(slug);
    if (!a || a.kind !== "ephemeral" || a.reportsTo !== callerId)
      return { ok: false as const, message: `@${slug} isn't an agent you spawned.` };

  /** Spec §8: latch (provisional) → one transaction → committed latch → hand-offs → stop. */
  async terminate(agentId: string, by: string, o: { latched?: boolean } = {}): Promise<{ status: "terminated" }> {
    const rt = await this.d.runtimes.load(agentId);
    if (!rt) throw new ApiError(404, "agent_not_found", "No such agent");
    if (rt.agent.kind !== "ephemeral") throw new ApiError(409, "not_ephemeral", "Only spawned agents can be terminated.");
    if (!o.latched) rt.markTerminated({ committed: false });
    let peerRows: PendingRow[] = [];
    try {
      const done = await this.d.db.transaction(async (tx) => {
        const spawnerId = rt.agent.reportsTo;
        if (spawnerId) await tx.select({ id: agents.id }).from(agents).where(eq(agents.id, spawnerId)).for("no key update");
        const [row] = await tx.select().from(agents).where(eq(agents.id, agentId)).for("no key update");
        if (!row) throw new ApiError(404, "agent_not_found", "No such agent");
        if (row.terminatedAt) return "already";
        const before = await this.d.router.snapshot(tx, agentId); // { managerId, peerIds } read in tx
        await this.d.store.terminateRows(tx, agentId, by);
        peerRows = await this.d.router.persistPeerEvents(tx, agentId, { kind: "left", reason: "terminated", by }, before,
          { excludeManager: by === (await spawnerSlug(tx, spawnerId)) });
        return "done";
      });
      rt.markTerminated({ committed: true });
      if (done === "already") return { status: "terminated" };
    } catch (err) {
      rt.unmarkTerminated();
      throw err;
    }
    this.d.router.handOffHeldRows(peerRows);
    void rt.terminateStop(by).catch((err: unknown) => this.d.log.error({ err, agent: rt.agent.slug }, "stopping a terminated agent failed"));
    return { status: "terminated" };
```

```ts
export class Reaper {
  private timer: ReturnType<typeof setInterval> | undefined;
  private running = false;
  constructor(private readonly d: ReaperDeps) {}
  start() { this.timer = setInterval(() => void this.run(), this.d.interval ?? SWEEP_INTERVAL_MS); }
  stop() { if (this.timer) clearInterval(this.timer); this.timer = undefined; }
  async run(): Promise<void> {
    if (this.running) return; // one sweep at a time
    this.running = true;
    try {
      const now = this.d.now();
      for (const a of await this.d.store.ttlCandidates(new Date(now - EPHEMERAL_TTL_MS))) {
        const rt = await this.d.runtimes.load(a.id);
        if (!rt || !(await rt.reaperCheck(now - EPHEMERAL_TTL_MS))) continue;
        await this.d.terminator.terminate(a.id, "@factory", { latched: true })
          .catch((err: unknown) => this.d.log.error({ err, agent: a.slug }, "TTL termination failed; retrying next sweep"));
      }
      const stillStuck = new Set<string>();
      for (const a of await this.d.store.stuckCandidates(new Date(now - 2 * SWEEP_INTERVAL_MS))) {
        const rt = await this.d.runtimes.load(a.id);
        const r = await rt?.sweepStuck().catch((err: unknown) => {
          this.d.log.error({ err, agent: a.slug }, "cleaning up a stuck termination failed");
          return "still" as const;
        });
        if (r === "still") stillStuck.add(a.id);
      }
      for (const a of await this.d.store.workspaceCandidates(new Date(now - WORKSPACE_GRACE_MS))) {
        if (stillStuck.has(a.id) || a.errorKind === "stop_failed") continue; // a live container may still mount it
        try {
          await this.d.workspace.deleteWorkspace(a.slug, async () => !(await this.d.store.agentById(a.id))?.workspacePinned);
          await this.d.store.setWorkspaceDeleted(a.id, new Date(this.d.now()));
        } catch (err) { this.d.log.error({ err, agent: a.slug }, "deleting a workspace failed; retrying next sweep"); }
      }
    } finally { this.running = false; }
  }
}
```
